# 05 — 布局与插槽

## 什么是布局 (Layout)

Layout 是用于提供可复用的 UI 结构的 Astro 组件，典型用途：

- 页面外壳（`<html>`、`<head>`、`<body>` 标签）
- 共享的导航栏、页脚
- 全局 CSS 引入

> Layout 本质上就是普通的 Astro 组件，没有特殊之处。只是按惯例放在 `src/layouts/` 目录下。

---

## 基本 Layout 示例

```astro
---
// src/layouts/BaseLayout.astro
import Footer from '../components/Footer.astro';

interface Props {
  title: string;
}
const { title } = Astro.props;
---

<html lang="zh-CN">
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>{title}</title>
    <link rel="icon" type="image/svg+xml" href="/favicon.svg" />
  </head>
  <body>
    <nav>
      <a href="/">首页</a>
      <a href="/about">关于</a>
    </nav>

    <main>
      <slot />  <!-- 页面内容注入到此 -->
    </main>

    <Footer />
  </body>
</html>

<style is:global>
  body {
    margin: 0;
    font-family: system-ui, sans-serif;
  }
</style>
```

在页面中使用 Layout：

```astro
---
// src/pages/index.astro
import BaseLayout from '../layouts/BaseLayout.astro';
---

<BaseLayout title="首页">
  <h1>欢迎来到我的网站</h1>
  <p>这是首页内容</p>
</BaseLayout>
```

## Layout 中的插槽详解

### 默认插槽

```astro
<slot />   <!-- 子组件内容将渲染在这里 -->
```

### 具名插槽

```astro
<!-- 定义 Layout -->
<div class="page">
  <header><slot name="header" /></header>
  <article><slot /></article>
  <footer><slot name="footer" /></footer>
</div>

<!-- 使用 Layout -->
<Layout>
  <nav slot="header">导航</nav>
  <p>文章内容（默认插槽）</p>
  <p slot="footer">© 2024</p>
</Layout>
```

### 检查插槽是否有内容

```astro
---
// 如果 'more' 插槽有内容才渲染 wrapper
---
{Astro.slots.has('more') && (
  <aside>
    <h2>更多</h2>
    <slot name="more" />
  </aside>
)}
```

### 异步渲染插槽内容

```astro
---
const html = await Astro.slots.render('default');
---
<Fragment set:html={html} />
```

## 布局的使用模式

### 嵌套 Layout

```astro
---
// src/layouts/BaseLayout.astro (基础布局)
---
<html>
  <head><!-- 通用 meta --></head>
  <body>
    <slot />
  </body>
</html>
```

```astro
---
// src/layouts/BlogLayout.astro (博客布局，继承基础布局)
import BaseLayout from './BaseLayout.astro';

interface Props {
  title: string;
  author: string;
}
const { title, author } = Astro.props;
---

<BaseLayout>
  <article>
    <header>
      <h1>{title}</h1>
      <p>作者: {author}</p>
    </header>
    <slot />
  </article>
</BaseLayout>
```

### Markdown 页面使用 Layout

```markdown
---
layout: ../layouts/BlogLayout.astro
title: 我的博客文章
author: 张三
---

## 文章内容

这是用 Markdown 写的文章内容。
```

## Layout 最佳实践

1. **Layout 中的 `<html>` 标签必须是所有元素的根**
2. **推荐使用 `interface Props` 定义 Layout 接收的属性**
3. **全局 CSS 放在 Layout 中引入**，使用 `<style is:global>`
4. **Layout 可以嵌套**，形成多层模板继承
5. **Layout 中可以包含 `<script>`**，支持客户端交互
6. **Layout 中可以包含 UI 框架组件**，但需注意渲染时机
