# 09 — 框架组件集成

> Astro 支持在 `.astro` 文件中直接使用 React、Preact、Svelte、Vue、Solid 等框架组件。

## 官方框架集成

| 框架 | 安装命令 |
|------|----------|
| React | `npx astro add react` |
| Preact | `npx astro add preact` |
| Svelte | `npx astro add svelte` |
| Vue | `npx astro add vue` |
| SolidJS | `npx astro add solid` |
| AlpineJS | `npx astro add alpinejs` |

---

## 使用框架组件

安装集成后，直接导入使用：

```astro
---
import MyReactComponent from '../components/MyReactComponent.jsx';
import MySvelteComponent from '../components/MySvelteComponent.svelte';
import MyVueComponent from '../components/MyVueComponent.vue';
---

<html>
  <body>
    <h1>混用框架组件</h1>
    <MyReactComponent />
    <MySvelteComponent />
    <MyVueComponent />
  </body>
</html>
```

### 文件扩展名规则

| 扩展名 | 框架 |
|--------|------|
| `.jsx` / `.tsx` | React / Preact / Solid |
| `.svelte` | Svelte |
| `.vue` | Vue |

> 多个 JSX 框架（如 React + Preact）需额外配置。

## 客户端岛屿 (Hydration)

框架组件默认渲染为静态 HTML，使用 `client:*` 指令使其变为交互式：

```astro
---
import InteractiveButton from '../components/InteractiveButton.jsx';
import Counter from '../components/Counter.svelte';
---

<!-- 页面加载时立即交互 -->
<InteractiveButton client:load />

<!-- 组件进入视口时交互 -->
<Counter client:visible />

<!-- 仅客户端渲染（不进行服务端渲染） -->
<SpecialComponent client:only="react" />
```

### 客户端指令完整列表

| 指令 | 加载时机 | 适用场景 |
|------|----------|----------|
| `client:load` | 页面加载立即加载 | 首屏必需交互的组件 |
| `client:idle` | 浏览器空闲时加载 | 非关键的交互组件 |
| `client:visible` | 组件进入视口时加载 | 页面底部/侧边组件 |
| `client:media={QUERY}` | 匹配媒体查询时加载 | 移动端/桌面端特定组件 |
| `client:only={FRAMEWORK}` | 仅客户端渲染 | 依赖浏览器 API 的组件 |

## 传递 Props

```astro
---
import TodoList from '../components/TodoList.jsx';
---

<TodoList
  title="待办事项"
  initialTodos={["学习 Astro", "审查 PR"]}
  count={42}
  isVisible={true}
/>
```

### Props 序列化限制

传递给交互组件（有 `client:*` 指令）的 props 必须可序列化：

| ✅ 支持 | ❌ 不支持 |
|---------|-----------|
| `string`, `number`, `boolean` | `function` |
| `Array`, `Object` | `Symbol`, `Map` 中的复杂键 |
| `Date`, `RegExp`, `URL` | `Promise`, `WeakMap` |
| `BigInt`, `Map`, `Set` | DOM 元素 |
| `Uint8Array` 等 TypedArray | 类实例 |

## 传递子元素

### React / Preact / Solid

```astro
<MyReactSidebar>
  <p>侧边栏内容</p>
  <h2 slot="title">标题</h2>   <!-- 具名插槽 → 转为 props.title -->
  <ul slot="social-links">...</ul>  <!-- kebab-case 转为 camelCase -->
</MyReactSidebar>
```

在 React 组件中接收：

```jsx
export default function MySidebar(props) {
  return (
    <aside>
      <header>{props.title}</header>
      <main>{props.children}</main>
      <footer>{props.socialLinks}</footer>
    </aside>
  );
}
```

### Svelte / Vue

```svelte
<aside>
  <header><slot name="title" /></header>
  <main><slot /></main>
  <footer><slot name="social-links" /></footer>
</aside>
```

## 嵌套框架组件

框架组件可以嵌套其他框架组件（在 `.astro` 文件中）：

```astro
---
import MyReactSidebar from '../components/MyReactSidebar.jsx';
import MyReactButton from '../components/MyReactButton.jsx';
import MySvelteButton from '../components/MySvelteButton.svelte';
---

<MyReactSidebar>
  <p>侧边栏</p>
  <div slot="actions">
    <MyReactButton client:idle />
    <MySvelteButton client:idle />
  </div>
</MyReactSidebar>
```

> 只有 `.astro` 文件可以混用多框架组件，`.jsx` 或 `.svelte` 文件中不能混用。

## 常见限制

### ❌ 不能在框架组件中导入 .astro 组件

```jsx
// ❌ 这行不通
// React 组件不能导入 .astro 组件
import MyAstroComponent from './MyAstroComponent.astro';
```

### ❌ 不能给 .astro 组件加 client: 指令

```astro
<!-- ❌ 报错！.astro 组件不能 hydration -->
<MyAstroComponent client:load />
```

需要交互的 .astro 组件请使用 `<script>` 标签。

### ✅ 用 slot 将 .astro 组件传给框架组件

```astro
<MyReactComponent>
  <MyAstroComponent slot="header" />
</MyReactComponent>
```

## 混合多框架配置

如果同时使用 React 和 Preact，需要在 `astro.config.mjs` 中配置：

```javascript
import { defineConfig } from 'astro/config';
import react from '@astrojs/react';
import preact from '@astrojs/preact';

export default defineConfig({
  integrations: [
    react({ include: '**/react/*' }),     // 只处理 react/ 目录下的 .jsx
    preact({ include: '**/preact/*' }),    // 只处理 preact/ 目录下的 .jsx
  ],
});
```
