# 07 — 客户端脚本与交互

## `<script>` 标签处理

Astro 默认对 `<script>` 标签进行处理：

- **TypeScript 支持**：默认所有脚本都是 TypeScript
- **导入打包**：支持导入本地文件和 npm 模块，自动打包
- **自动模块化**：处理后的脚本自动成为 `type="module"`
- **去重**：同一组件在页面中使用多次，脚本只包含一次
- **自动内联**：小脚本自动内联到 HTML 中

```astro
<script>
  // 被处理！打包！支持 TypeScript！
  // 支持导入本地脚本和 npm 包
  import confetti from 'canvas-confetti';
  console.log('Hello from Astro!');
</script>
```

### 不被处理的脚本

如果 `<script>` 有除 `src` 外的任何属性，将不被处理：

```astro
<script is:inline>
  // 原样输出到 HTML
  // 不支持 TypeScript，不支持 import 解析
  // 如果组件使用多次，此代码会重复
</script>
```

## 引入外部脚本

### 从 `src/` 引入（会被处理）

```astro
<script src="../scripts/local.js"></script>
<script src="./script-with-types.ts"></script>
```

### 从 `public/` 或 CDN 引入（需加 `is:inline`）

```astro
<script is:inline src="/my-script.js"></script>
<script is:inline src="https://my-analytics.com/script.js"></script>
```

## 事件处理

Astro 遵循标准 HTML，**不使用自定义事件语法**。用 `addEventListener`：

```astro
<button class="alert">点击我</button>

<script>
  const buttons = document.querySelectorAll('button.alert');
  buttons.forEach((button) => {
    button.addEventListener('click', () => {
      alert('Button was clicked!');
    });
  });
</script>
```

> **注意：** 脚本只打包一次，使用 `querySelectorAll` 确保所有实例都能绑定事件。

## 使用 Web Components 自定义元素

### 基本示例

```astro
<astro-heart>
  <button aria-label="Heart">💜</button> × <span>0</span>
</astro-heart>

<script>
  class AstroHeart extends HTMLElement {
    connectedCallback() {
      let count = 0;
      const heartButton = this.querySelector("button");
      const countSpan = this.querySelector("span");

      if (heartButton && countSpan) {
        heartButton.addEventListener("click", () => {
          count++;
          countSpan.textContent = count.toString();
        });
      }
    }
  }
  customElements.define("astro-heart", AstroHeart);
</script>
```

### 优势

- **作用域安全**：`this.querySelector()` 只搜索当前组件实例
- **多实例支持**：`connectedCallback()` 在每次找到 `<astro-heart>` 时都会运行
- **无需框架**：用原生 Web API 实现交互

## 将前端变量传给脚本

通过 `data-*` 属性传递：

```astro
---
const { message = 'Welcome, world!' } = Astro.props;
---

<astro-greet data-message={message}>
  <button>Say hi!</button>
</astro-greet>

<script>
  class AstroGreet extends HTMLElement {
    connectedCallback() {
      const message = this.dataset.message;
      const button = this.querySelector('button');
      button?.addEventListener('click', () => {
        alert(message);
      });
    }
  }
  customElements.define('astro-greet', AstroGreet);
</script>
```

使用：

```astro
<AstroGreet />
<AstroGreet message="欢迎！" />
```

### 使用 `define:vars` 指令

```astro
---
const message = "Astro is awesome!";
---

<script define:vars={{ message }}>
  alert(message);
</script>
```

> ⚠️ `define:vars` 会使 `<script>` 变成 `is:inline` 内联脚本，不会被打包。推荐使用上面 `data-*` 属性的方式。

## 常见交互模式

### 简单点击事件

```astro
<button data-click>计数: <span>0</span></button>

<script>
  document.querySelectorAll('[data-click]').forEach(btn => {
    const span = btn.querySelector('span');
    let count = 0;
    btn.addEventListener('click', () => {
      span.textContent = String(++count);
    });
  });
</script>
```

### 表单提交

```astro
<form data-contact>
  <input type="email" placeholder="请输入邮箱" required />
  <button type="submit">提交</button>
</form>

<script>
  const form = document.querySelector('[data-contact]');
  form?.addEventListener('submit', async (e) => {
    e.preventDefault();
    const email = new FormData(form).get('email');
    const res = await fetch('/api/contact', {
      method: 'POST',
      body: JSON.stringify({ email }),
    });
    if (res.ok) alert('提交成功！');
  });
</script>
```

### 与 UI 框架组件配合

> 如果脚本需要处理 UI 框架组件的元素，推荐使用 Web Components 自定义元素，它会自动与框架组件的渲染周期协调。

---

## 脚本处理总结

| 场景 | 推荐方式 |
|------|----------|
| 简单 DOM 操作 | `<script>` + `querySelectorAll` |
| 多实例组件交互 | Web Components (`customElements.define`) |
| 传递组件 Props 到客户端 | `data-*` 属性 |
| 外部库导入 | `<script>` 中 `import` |
| 第三方统计脚本 | `<script is:inline src="URL">` |
| 复杂交互 (需要状态管理) | 使用 UI 框架 (React/Vue) + `client:*` 指令 |
