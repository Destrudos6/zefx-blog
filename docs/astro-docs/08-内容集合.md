# 08 — 内容集合 (Content Collections)

> **适用场景：** 管理成组的结构化内容（博客文章、产品描述、人物档案等）

## 什么是内容集合？

内容集合是一组相关的、结构相同的数据条目。可以是本地文件（Markdown 目录），也可以是远程数据（CMS、数据库）。

```
src/content/
├── blog/                 # "blog" 集合
│   ├── post1.md
│   ├── post2.md
│   └── post3.md
└── authors/              # "authors" 集合
    └── authors.json
```

---

## 两种集合类型

| 类型 | 加载时机 | 适用场景 |
|------|----------|----------|
| **构建时集合 (Build-time)** | 构建时 | 博客文章、产品描述等相对静态的内容 |
| **实时集合 (Live)** | 请求时 | 实时库存、用户特定数据等频繁变化的内容 |

## 定义构建时集合

### 1. 创建配置文件

```typescript
// src/content.config.ts

import { defineCollection } from 'astro:content';
import { glob, file } from 'astro/loaders';
import { z } from 'astro/zod';

const blog = defineCollection({
  // 使用 glob() 加载多文件
  loader: glob({ pattern: '**/*.{md,mdx}', base: './src/content/blog' }),
  // 定义数据模式（Zod 验证）
  schema: z.object({
    title: z.string(),
    description: z.string(),
    pubDate: z.coerce.date(),
    updatedDate: z.coerce.date().optional(),
    tags: z.array(z.string()).default([]),
    draft: z.boolean().default(false),
  }),
});

const authors = defineCollection({
  // 使用 file() 加载单文件
  loader: file('src/data/authors.json'),
  schema: z.object({
    name: z.string(),
    avatar: z.string().url(),
  }),
});

export const collections = { blog, authors };
```

### 2. 在页面中使用

```astro
---
import { getCollection, getEntry } from 'astro:content';

// 获取所有博客文章
const allPosts = await getCollection('blog');

// 获取单篇文章
const post = await getEntry('blog', 'post1');

// 过滤（手动）
const publishedPosts = allPosts.filter(post => !post.data.draft);
---
```

## 加载器 (Loaders)

### `glob()` 加载器

从目录中加载多个文件，支持 `.md`、`.mdx`、`.json`、`.yaml`、`.toml`：

```typescript
import { glob } from 'astro/loaders';

const blog = defineCollection({
  loader: glob({
    pattern: '**/*.md',        // 匹配模式
    base: './src/content/blog', // 基础路径
    // 自定义 ID 生成
    generateId: ({ entry }) => entry.replace(/\.md$/, ''),
  }),
});
```

### `file()` 加载器

从单个文件中加载多个条目，支持 `.json`、`.yaml`：

```typescript
import { file } from 'astro/loaders';

const dogs = defineCollection({
  loader: file('src/data/dogs.json'),
});
```

JSON 文件格式可以是数组或对象：

```json
// 数组形式（每个对象需有 id 字段）
[
  { "id": "poodle", "coat": "curly" },
  { "id": "afghan", "coat": "short" }
]

// 对象形式（key 作为 id）
{
  "poodle": { "coat": "curly" },
  "afghan": { "coat": "short" }
}
```

### 自定义加载器

可以从 CMS、数据库、API 端点构建自定义加载器：

```typescript
// src/loaders/my-loader.ts
import type { Loader } from 'astro/loaders';

export function myLoader({ url }: { url: string }): Loader {
  return {
    name: 'my-loader',
    async load({ store, logger }) {
      const data = await fetch(url).then(r => r.json());
      for (const item of data) {
        store.set({
          id: item.id,
          data: item,
        });
      }
    },
  };
}
```

## 从集合生成路由

```astro
---
// src/pages/blog/[...slug].astro
import { getCollection } from 'astro:content';
import { render } from 'astro:content';

export async function getStaticPaths() {
  const posts = await getCollection('blog');
  return posts.map(post => ({
    params: { slug: post.id },
    props: { post },
  }));
}

const { post } = Astro.props;
const { Content } = await render(post);
---

<html>
  <head><title>{post.data.title}</title></head>
  <body>
    <article>
      <h1>{post.data.title}</h1>
      <time>{post.data.pubDate.toLocaleDateString()}</time>
      <Content />  <!-- 渲染 Markdown 内容 -->
    </article>
  </body>
</html>
```

## 实时集合 (Live Collections)

从远程数据源获取实时数据：

```typescript
import { defineCollection } from 'astro:content';
import { z } from 'astro/zod';

const products = defineCollection({
  type: 'live',  // 标记为实时集合
  schema: z.object({
    name: z.string(),
    price: z.number(),
    inStock: z.boolean(),
  }),
});
```

使用时调用专门的 API：

```astro
---
import { getLiveCollection } from 'astro:content';
const products = await getLiveCollection('products');
---
```

### 实时集合限制

| 功能 | 是否支持 |
|------|----------|
| MDX 渲染 | ❌ |
| 图片优化 | ❌ |
| 数据存储持久化 | ❌ |
| 性能 | 每次请求获取数据 |
| 动态过滤 | ✅ |

## Zod Schema 类型参考

```typescript
import { z } from 'astro/zod';

const schema = z.object({
  // 基础类型
  title: z.string(),
  count: z.number(),
  published: z.boolean(),

  // 可选值
  description: z.string().optional(),

  // 默认值
  tags: z.array(z.string()).default([]),

  // 日期
  pubDate: z.coerce.date(),        // 自动解析日期字符串
  updatedDate: z.coerce.date().optional(),

  // 枚举
  status: z.enum(['draft', 'published', 'archived']),

  // 联合类型
  type: z.union([z.literal('post'), z.literal('page')]),

  // URL
  image: z.string().url(),

  // 嵌套对象
  author: z.object({
    name: z.string(),
    email: z.string().email(),
  }),
});
```

## TypeScript 配置要求

如果使用了 `base` 模板，需要添加以下配置：

```json
{
  "compilerOptions": {
    "strictNullChecks": true,
    "allowJs": true
  }
}
```

> `strict` 和 `strictest` 模板已包含这些设置，无需额外配置。
