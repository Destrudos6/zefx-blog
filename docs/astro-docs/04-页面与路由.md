# 04 — 页面与路由

## 文件路由 (File-based Routing)

Astro 使用**文件路由**策略：`src/pages/` 中的每个文件自动成为网站的一个页面。

```
src/pages/
├── index.astro         → /
├── about.astro         → /about
├── about/
│   └── team.astro      → /about/team
├── posts/
│   ├── first-post.md   → /posts/first-post
│   └── [slug].astro    → /posts/:slug (动态路由)
├── 404.astro           → 自定义 404 页面
├── 500.astro           → 自定义 500 页面（SSR 模式）
└── rss.xml.js          → /rss.xml (端点)
```

### 支持的页面文件类型

| 扩展名 | 说明 |
|--------|------|
| `.astro` | Astro 组件页面 |
| `.md` | Markdown 页面 |
| `.mdx` | MDX 页面（需安装 MDX 集成） |
| `.html` | HTML 页面 |
| `.js` / `.ts` | 端点 (Endpoint) |

### 页面之间跳转

使用标准 HTML `<a>` 元素，**使用相对于根域的 URL 路径**：

```astro
<p>了解更多<a href="/about/">关于我们</a></p>
<p>查看文章<a href="/posts/first-post">第一篇文章</a></p>
```

## 静态路由 (Static Routes)

默认模式，所有页面在构建时预渲染。

```
src/pages/index.astro        → mysite.com/
src/pages/about.astro        → mysite.com/about
src/pages/about/index.astro  → mysite.com/about
src/pages/about/me.astro     → mysite.com/about/me
src/pages/posts/1.md         → mysite.com/posts/1
```

---

## 动态路由 (Dynamic Routes)

### 静态模式 (SSG) — 使用 `getStaticPaths()`

```astro
---
// src/pages/dogs/[dog].astro
export function getStaticPaths() {
  return [
    { params: { dog: "clifford" }},
    { params: { dog: "rover" }},
    { params: { dog: "spot" }},
  ];
}
const { dog } = Astro.params;
---
<div>Good dog, {dog}!</div>
```

生成三个页面：`/dogs/clifford`、`/dogs/rover`、`/dogs/spot`

### 多参数动态路由

```astro
---
// src/pages/[lang]-[version]/info.astro
export function getStaticPaths() {
  return [
    { params: { lang: "en", version: "v1" }},
    { params: { lang: "fr", version: "v2" }},
  ];
}
const { lang, version } = Astro.params;
---
```

生成：`/en-v1/info` 和 `/fr-v2/info`

### Rest 参数 `[...path]`

匹配任意深度的路径：

```astro
---
// src/pages/sequences/[...path].astro
export function getStaticPaths() {
  return [
    { params: { path: "one/two/three" }},
    { params: { path: "four" }},
    { params: { path: undefined }},   // 匹配顶层
  ];
}
const { path } = Astro.params;
---
```

生成：`/sequences/one/two/three`、`/sequences/four`、`/sequences`

### 带 Props 的动态路由

```astro
---
export function getStaticPaths() {
  const pages = [
    { slug: undefined,  title: "首页", text: "欢迎" },
    { slug: "products", title: "产品", text: "产品列表" },
  ];
  return pages.map(({ slug, title, text }) => ({
    params: { slug },
    props: { title, text },
  }));
}
const { title, text } = Astro.props;
---
<h1>{title}</h1>
<p>{text}</p>
```

## 按需渲染模式 (SSR) 的动态路由

需要先添加适配器（Adapter），然后：

```astro
---
// src/pages/resources/[resource]/[id].astro
export const prerender = false;   // 关闭预渲染
const { resource, id } = Astro.params;
---
<h1>{resource}: {id}</h1>
```

此页面会响应任意 `resource` 和 `id` 的值。

```markdown
---
# src/pages/page.md
layout: ../layouts/MySiteLayout.astro

```

### 自定义 404 页面

```astro
---
// src/pages/404.astro
---
<h1>页面未找到</h1>
<p>您访问的页面不存在。</p>
```

### 自定义 500 页面（SSR 模式）

```astro
---
// src/pages/500.astro
interface Props {
  error: unknown;
}
const { error } = Astro.props;
---
<div>{error instanceof Error ? error.message : "未知错误"}</div>
```

## 重定向 (Redirects)

### 配置重定向 (astro.config.mjs)

```javascript
// astro.config.mjs
export default defineConfig({
  redirects: {
    '/old-page': '/new-page',
    '/blog': 'https://example.com/blog',
    // 支持动态路由
    '/blog/[...slug]': '/articles/[...slug]',
    // 带状态码
    '/old': {
      status: 302,
      destination: '/new'
    }
  }
});
```

### 动态重定向

```astro
---
if (!isLoggedIn) {
  return Astro.redirect("/login", 302);
}
---
```

## 路由优先级规则

当多个路由可能匹配同一个 URL 时，按以下规则优先：

1. **内部保留路由**（`_astro/`、`_server_islands/`、`_actions/`）
2. **路径段更多的路由**
3. **静态路由 > 动态路由**（`/posts/create` > `/posts/[page]`）
4. **命名参数 > Rest 参数**（`[page]` > `[...slug]`）
5. **预渲染路由 > 服务端动态路由**
6. **端点 > 页面**
7. **文件路由 > 重定向**
8. 按字母顺序排序

## 重写 (Rewrites)

重写允许在**不改变浏览器 URL** 的情况下提供不同路由的内容：

```astro
---
// 当访问 /es-cu/articles/introduction 时，显示西班牙语版本
return Astro.rewrite("/es/articles/introduction");
---
```

适用于：同一内容的不同语言变体、SEO 友好的多路径展示。
