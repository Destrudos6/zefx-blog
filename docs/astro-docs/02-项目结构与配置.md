# 02 — 项目结构与配置

## Astro 项目目录结构

```
/
├── public/                    # 静态资源（不经过 Astro 处理）
│   ├── favicon.svg
│   └── robots.txt
├── src/                       # 项目源代码
│   ├── assets/                # 图片等资源文件
│   ├── components/            # .astro 组件 / UI 框架组件
│   │   ├── Header.astro
│   │   └── Button.jsx
│   ├── layouts/               # 布局组件
│   │   └── Layout.astro
│   ├── pages/                 # ⭐ 页面路由（必需的目录）
│   │   ├── index.astro        # → /
│   │   ├── about.astro        # → /about
│   │   └── posts/[slug].astro # → /posts/:slug
│   ├── styles/                # CSS 文件
│   │   └── global.css
│   └── content.config.ts      # 内容集合配置
├── astro.config.mjs           # Astro 配置文件
├── tsconfig.json              # TypeScript 配置
├── package.json               # 依赖和脚本
└── .gitignore
```

### 目录说明

| 目录 | 作用 | 是否必需 |
|------|------|----------|
| `src/pages/` | 页面路由，每个文件自动成为路由 | ✅ **必需** |
| `src/components/` | 可复用组件（Astro 或 React/Vue 等） | 约定非必需 |
| `src/layouts/` | 布局组件 | 约定非必需 |
| `src/content/` | 内容集合（博客文章等 Markdown 数据） | 按需 |
| `public/` | 静态文件（不经过构建处理） | 按需 |

### `src/` vs `public/`

| | `src/` | `public/` |
|--|--------|-----------|
| 处理方式 | Astro 处理、优化、打包 | 原样复制到构建目录 |
| 适合存放 | 组件、页面、CSS、图片 | favicon、robots.txt、PDF |
| 引用方式 | ESM import | 绝对路径 `/favicon.svg` |

## `astro.config.mjs` 配置文件

```javascript
// @ts-check
import { defineConfig } from 'astro/config';

// https://astro.build/config
export default defineConfig({
  // 站点 URL（部署时必需，用于生成 sitemap 等）
  site: 'https://example.com',
  base: '/',                    // 部署在子路径时设置

  // 输出模式
  output: 'static',             // 'static' | 'server' | 'hybrid'

  // 集成（插件）
  integrations: [],

  // 构建选项
  build: {
    format: 'directory',        // URL 格式
    assets: '_astro',           // 静态资源前缀
  },

  // 开发服务器
  devToolbar: {
    enabled: true,              // 开发工具栏
  },

  // 服务端渲染适配器
  adapter: undefined,

  // Vite 配置（可覆盖）
  vite: {
    ssr: {
      noExternal: [],
    },
  },

  // 重定向
  redirects: {
    '/old-page': '/new-page',
  },
});
```

### 常用配置项速查

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `site` | string | — | 部署后的完整 URL |
| `base` | string | `/` | 子路径部署时设置 |
| `output` | `'static'\|'server'\|'hybrid'` | `'static'` | 渲染模式 |
| `integrations` | array | `[]` | 集成列表 |
| `redirects` | object | `{}` | 路由重定向 |
| `adapter` | object | — | SSR 适配器 |
| `build.format` | string | `'directory'` | URL 格式 |
| `scopedStyleStrategy` | string | `'attribute'` | 样式作用域策略 |

## `tsconfig.json` TypeScript 配置

Astro 内置 TypeScript 支持。推荐从官方模板继承：

```json
{
  "extends": "astro/tsconfigs/strict",
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "react"
  }
}
```

Astro 提供的模板：
- `astro/tsconfigs/base` — 基础
- `astro/tsconfigs/strict` — 严格模式 (推荐)
- `astro/tsconfigs/strictest` — 最严格

## `package.json` 脚本说明

```json
{
  "scripts": {
    "dev": "astro dev",              // 启动开发服务器
    "build": "astro build",          // 构建生产版本
    "preview": "astro preview",      // 预览构建结果
    "astro": "astro"                 // 运行 astro CLI
  }
}
```

### 依赖管理建议

> Astro 官方推荐**将所有依赖放在 `dependencies` 中**，只在有特殊需求时才用 `devDependencies`。

## 路径别名 (Aliases)

通过 `tsconfig.json` 配置，避免深层相对路径：

```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["src/*"],
      "@components/*": ["src/components/*"]
    }
  }
}
```

```astro
---
// 使用别名
import Header from '@components/Header.astro';
---
```
