# 01 — 快速入门与核心概念

## 什么是 Astro？

Astro 是一个用于构建**内容驱动型网站**（content-driven websites）的 Web 框架，尤其适合博客、营销页、电商、文档站等。它的核心创新在于**岛屿架构（Islands Architecture）**，大幅减少了 JavaScript 的开销。

### Astro 的核心理念

| 理念 | 说明 |
|------|------|
| **内容优先 (Content-driven)** | 专为展示内容而设计，而非构建复杂 Web 应用 |
| **服务端优先 (Server-first)** | 尽可能在服务端渲染 HTML，而非客户端 |
| **默认极速 (Fast by default)** | 几乎不可能用 Astro 构建出慢网站 |
| **易用 (Easy to use)** | 任何有效 HTML 都是有效 Astro 模板语法 |
| **开发者友好 (Developer-focused)** | 优秀的 CLI、VS Code 插件、TypeScript 支持 |

### 性能数据

- Astro 网站比同等的 React 网站 **加载快 40%**，**JavaScript 少 90%**
- 默认输出零 JS 的静态 HTML
- 只在需要交互的地方选择性加载 JS

## 岛屿架构 (Islands Architecture)

### 什么是岛屿？

岛屿（Island）是静态 HTML 页面中独立的交互式 UI 组件。

```
┌──────────────────────────────────┐
│  Header (交互式岛屿 client:load)  │
├──────────────────────────────────┤
│  侧边栏 (静态 HTML)               │
├──────────────────────────────────┤
│  静态内容：文字、图片等            │
├──────────────────────────────────┤
│  图片轮播 (交互式岛屿 client:visible)│
├──────────────────────────────────┤
│  Footer (静态 HTML)               │
└──────────────────────────────────┘
```

### 客户端岛屿 (Client Islands)

- 默认所有组件渲染为**纯静态 HTML**，**剔除所有客户端 JS**
- 使用 `client:*` 指令将组件变为交互式岛屿
- JS 只会为显式标记的组件加载

| 指令 | 加载时机 |
|------|----------|
| `client:load` | 页面加载时立即加载 |
| `client:idle` | 浏览器空闲时加载 |
| `client:visible` | 组件进入视口时加载 |
| `client:media={QUERY}` | 匹配媒体查询时加载 |
| `client:only={FRAMEWORK}` | 仅客户端渲染（不进行服务端渲染） |

### 服务端岛屿 (Server Islands)

- 使用 `server:defer` 指令将组件延迟服务端渲染
- 页面主要内容先渲染，个性化内容后加载
- 适合：用户头像、特价信息、评论等

```astro
---
import Avatar from "../components/Avatar.astro";
---
<Avatar server:defer>
  <svg slot="fallback" class="generic-avatar">...</svg>
</Avatar>
```

### 岛屿的优势

1. **性能**：大部分网站转为快速静态 HTML
2. **并行加载**：不同岛屿独立加载，互不阻塞
3. **按需加载**：昂贵的组件只在可见时加载
4. **多框架混用**：同一页面可同时使用 React + Vue + Svelte

## 设计原则详解

### 服务端优先 vs SPA

| 特性 | Astro (MPA) | 传统 JS 框架 (SPA) |
|------|-------------|-------------------|
| 渲染位置 | 服务端 | 客户端 |
| 默认 JS | 零 JS 输出 | 大量 JS bundle |
| 首屏性能 | 极快 | 依赖 JS 执行 |
| 适用场景 | 内容站点 | 复杂 Web 应用 |

### 容易上手

- **只需 HTML + CSS 就能写 "Hello World"**
- `.astro` 语法是 HTML 的超集
- 支持 React/Preact/Svelte/Vue/Solid 等框架组件
- 无需学习 hooks、refs、observables 等响应式概念
- **"按需引入复杂度 (opt in to complexity)"** — 从简单开始，逐步添加高级功能

## 常用命令速查

```bash
npm create astro@latest        # 创建新项目
npm run dev                    # 启动开发服务器 (localhost:4321)
npm run build                  # 构建生产版本到 dist/
npm run preview                # 预览构建后的站点
npx astro add <集成名称>        # 添加集成 (react/tailwind/sitemap 等)
npx astro check                # 运行类型检查
npx astro --help               # 查看所有 CLI 命令

# 后台模式 (推荐，不占终端)
npx astro dev --background     # 后台启动
npx astro dev stop             # 停止
npx astro dev status           # 查看状态
npx astro dev logs             # 查看日志
```
